# Ivy — descargas

Binarios públicos de Ivy, el launcher de voz. El código vive en un repo privado.

## Versiones

| release | archivo | notas |
|---|---|---|
| v0.1 | `ivy-0.1-arm64.apk` | primera build instalable, solo arm64 |

Descarga directa:

```
https://github.com/samuel-nextstation/ivy-releases/releases/download/v0.1/ivy-0.1-arm64.apk
```

Requiere Android 8 (API 26) o superior en un teléfono arm64. No está en Play Store:
hay que permitir "instalar apps desconocidas" para el navegador o el gestor de archivos.
